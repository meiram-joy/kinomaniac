# Глоссарий «Киноманьяка»

**Каталог** — список Фильмов, из которых программа имеет право советовать. Единственный источник правды о названии, годе, длительности и описании.

**Фильм** — запись Каталога: id, название, год, длительность в минутах, жанры, страны, языки, описание.

**id фильма** — строка вида `f-001`, уникальная в Каталоге. Модель называет фильм только через id, никогда через название.

**Чужой id** — id, который вернула модель, но которого нет в Каталоге, переданном в Подбор. Пользователь его не видит.

**Запрос** — свободный текст пользователя («как Интерстеллар, но не про космос»).

**Подбор** — один ответ программы на Запрос: от одного до трёх Фильмов из Каталога с причиной (`why`) у каждого, либо честное «ничего нет».

**Исход** — итог одного Подбора одним словом: `ok`, `no_match`, `invalid`, `refusal`, `length`, `no_connection`, `error_<код>`. Фильмы показываются только при `ok`.

**Починка ответа** — исправление безвредных ошибок модели без потери ответа: повторы id убираются, лишние фильмы сверх трёх отбрасываются. Чужой id не чинится: из-за него весь ответ становится `invalid`.

**Противоречивый ответ** — статус модели не сходится с её списком фильмов. `no_match` с фильмами трактуется как `no_match`, `ok` без фильмов — как `invalid`.

**Журнал** — по одной записи на каждый вызов модели: модель, что ушло модели, Исход, отклонённые id, токены и цена.

**Набор запросов** — фиксированный список Запросов с Ожиданиями, на котором меряется качество Подбора.

**Ожидание** — что считается правильным Подбором для Запроса из Набора: `no_match` (в Каталоге ответа нет), `must` (хотя бы один из этих Фильмов должен быть в выдаче), `forbid` (ни одного из этих).

**Словарь каталога** — закрытый список слов для жанров, языков и стран (по-русски, строчными; «Казахстан» с большой буквы). Только эти слова допустимы в Фильме.
